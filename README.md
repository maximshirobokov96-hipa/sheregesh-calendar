# sheregesh-calendar
Интерактивный веб-календарь сезонов Шерегеш (2026–2027) — это автономное приложение на HTML/CSS/JS для визуализации спроса на курорте. Оно цветом выделяет высокий, умеренный и низкий сезоны, а красным — государственные праздники. Красная точка в углу даты сигнализирует о неочевидных праздниках (День снега, 14 февраля и др.)
